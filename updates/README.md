# سازوکار بروزرسانی SRMS (فایل‌های `.srms-update`)

هر تغییر پایگاه‌داده / تنظیمات / داده / فایل استاتیک را می‌توان بدون نصب مجدد،
از طریق صفحه‌ی **«بروزرسانی»** در سایدبار و با آپلود یک فایل `.srms-update` اعمال کرد.

## ساختار فایل

```jsonc
{
  "format": "srms-update",        // الزامی — امضای قالب
  "formatVersion": 1,
  "version": "1.2.0",             // الزامی — semver و بزرگ‌تر از نسخه فعلی
  "minVersion": "1.0.0",          // اختیاری — حداقل نسخه مورد نیاز
  "title": "عنوان نسخه",
  "changelog": ["تغییر ۱", "تغییر ۲"],   // الزامی — پس از اعمال به کاربر نمایش داده می‌شود
  "database": {
    "sql": "ALTER TABLE ...;",          // اسکریپت اعمال (چند دستوری مجاز)
    "rollbackSql": "ALTER TABLE ...;"   // اسکریپت بازگشت (برای Rollback یک‌کلیکه)
  },
  "settings": {
    "widgetSettings": { "quoteText": "..." },
    "customFields":  [ { "fieldKey": "...", "label": "..." } ],
    "notificationRules": [ { "name": "...", "dateField": "marriage_date" } ]
  },
  "files": [
    { "path": "public/img/logo.png", "contentBase64": "...." }  // فقط زیر public/
  ]
}
```

## قواعد

- نسخه باید از نسخه فعلی سامانه جدیدتر باشد (عدد نسخه تکراری/کوچک‌تر رد می‌شود).
- همه‌ی تغییرات پایگاه‌داده در یک **تراکنش** اعمال می‌شوند؛ در صورت خطا همه‌چیز به حالت قبل برمی‌گردد.
- قبل از اعمال، **نسخه‌ی قبلیِ** تنظیمات/فیلدها/قوانین/فایل‌ها اسنپ‌شات (Snapshot) گرفته می‌شود تا «بازگشت به نسخه قبل» دقیقاً همان حالت قبلی را بازگرداند.
- فایل‌ها فقط زیر `public/` مجازند (امنیت).
- پس از اعمال، لیست تغییرات (changelog) در پیام موفقیت و در تاریخچه نسخه‌ها نمایش داده می‌شود.

## تاریخچه و بازگشت

- لیست کامل بروزرسانی‌ها + نسخه فعلی در همان صفحه قابل مشاهده است.
- «بازگشت به نسخه قبل»: آخرین نسخه را لغو می‌کند.
- «بازگشت به این نسخه»: همه‌ی نسخه‌های جدیدتر از مقصد را به ترتیبِ معکوس لغو می‌کند (پیمایش یک‌کلیکه بین نسخه‌ها).

## ساخت خودکار فایل بروزرسانی (با هر تغییر سامانه)

با هر تغییری که در ساختار پایگاه‌داده/تنظیمات ایجاد می‌شود، یک فایل بروزرسانی جدید ساخته و
در همین پوشه قرار می‌گیرد:

```bash
node scripts/build-update.mjs                       # نسخه‌ی بعدی (minor bump)
node scripts/build-update.mjs 1.5.0                 # نسخه‌ی مشخص
node scripts/build-update.mjs 1.5.0 changelog.txt   # فهرست تغییرات از فایل متنی
SRMS_CHANGELOG="تغییر اول|تغییر دوم" node scripts/build-update.mjs
```

- شماره نسخه به‌صورت خودکار از آخرین فایل موجود در همین پوشه محاسبه می‌شود.
- اسکریپت SQL اعمالی و اسکریپت بازگشت (rollback) در همان فایل ذخیره می‌شود.
- اعمال از صفحه‌ی «🚀 بروزرسانی سامانه» انجام می‌شود و کاملاً تراکنشی و بازگشت‌پذیر است.

## نسخه‌های ارائه‌شده

| فایل | تغییرات |
|---|---|
| `srms-update-v1.1.0.srms-update` | نسخه‌ی پایه‌ی موتور بروزرسانی |
| `srms-update-v1.2.0.srms-update` | بهبود موتور نامه و قوانین اعلان |
| `srms-update-v1.3.0.srms-update` | بهبود گزارش‌ها و ایمپورت اکسل |
| `srms-update-v1.4.0.srms-update` | **ویرایشگر گرافیکی نامه (WYSIWYG)**، فیلتر «سربازان در حال خدمت» در انتخاب گیرندگان + آپلود اکسل، **ماژول پشتیبان‌گیری/بازیابی** با زمان‌بند خودکار و ایندکس‌های بهینه‌سازی |

> نکته: برای نصب نسخه‌ی ۱.۴.۰ لازم نیست نسخه‌های قبلی را جداگانه اعمال کنید؛ کافی است این
> فایل را در صفحه‌ی بروزرسانی آپلود کنید. همه‌ی دستورات SQL آن idempotent هستند.
